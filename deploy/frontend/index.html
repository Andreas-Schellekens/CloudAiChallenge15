Never decide whether to eat a mushroom with this tool. It is a student model trained on a deliberately noisy dataset (about 2% of the labels are flipped) and it is wrong often. It is tuned to catch 90% of poisonous mushrooms, which it pays for by calling roughly two thirds of the edible ones poisonous as well.

Observations

Leave anything you did not observe empty. Empty is a real input: the model was trained on a dataset where only 12 of 5000 rows were complete. Note that "none (absent)" and "Not observed" are different answers — a mushroom with no ring is not the same as a ring you did not check.
