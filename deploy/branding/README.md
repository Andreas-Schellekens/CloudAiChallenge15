# Fieldcast branding

Fieldcast connects observing the world with exploring model predictions.
Tagline: **Observe. Model. Explore.**

- [Logo](fieldcast-logo.png): horizontal lockup, transparent, for light backgrounds.
- [App icon](fieldcast-app-icon.png): standalone F symbol, transparent.
- [Palette](fieldcast-palette.png): five brand colours.
- [Typography](fieldcast-typography.png): Outfit and JetBrains Mono direction.
- [Ribbon](fieldcast-ribbon.png): transparent decorative motif.
- [UI example](fieldcast-ui-example.png): illustrative forecast card, not model output.

## Colour specification

| Colour | Hex | Use |
|---|---|---|
| Iris | `#6269F5` | Brand mark and large accents |
| Ink | `#17191F` | Text and dark surfaces |
| Paper | `#F3F2ED` | Light surfaces |
| Mist | `#E7E8F0` | Secondary surfaces |
| Moss | `#B6C8A0` | Supporting nature accent |

Use these exact hex values in code; generated raster colours may vary slightly.
The typography image is a visual specimen; use the actual Outfit and JetBrains Mono fonts for interface text.
The wordmark is custom artwork, not a font file.

## Usage

Keep the logo's aspect ratio and clear space of at least one ribbon thickness.
Use the standalone mark at small sizes and omit the tagline in a compact header.
Use Ink text on Iris controls; check contrast when selecting smaller text colours.
Reserve semantic status colours for prediction states, with explicit labels.
Use ribbons as occasional framing, away from text and important controls.

These PNG assets were created with built-in image generation. Full prompts are in
[PROMPTS.md](PROMPTS.md). The set is separate from the deployed frontend; this work
does not rename the Vercel project or publish the identity.
